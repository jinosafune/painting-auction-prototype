# painting-auction-prototype

絵画オークションサービスのUIプロトタイプです。実際の売買機能は無く、フロントエンドのモックアップとして動作します。

## ファイル構成

- `index.html` — ランディングページ(出品作品一覧・入札モーダル・出品フォームを含む単一HTML)
- `painting-auction-prototype.jsx` — モバイルアプリ想定のReactプロトタイプ(ホーム / 詳細・入札 / 出品 / マイページの4画面)

## 特徴

- 出品作品の一覧表示と、せり上がり式の入札シミュレーション(他の入札者によるライブ入札を疑似的に再現)
- 出品(鑑定申請)フォーム
- マイページでの本人確認・入札中オークションの表示

## 動かし方

`index.html` はブラウザで直接開くだけで確認できます。
`painting-auction-prototype.jsx` はReact環境(CodeSandboxなど)にコピーして実行してください。

## 画像について

`images/` 以下のサンプル画像は、Wikimedia Commonsで公開されているパブリックドメインの絵画作品(葛飾北斎、マレーヴィチ、セザンヌ、カンディンスキー)を、プロトタイプの見た目確認用に使用しています。実際のサービスでは出品者がアップロードした画像に差し替わります。
